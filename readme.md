# AgroConecta 🌾

O **AgroConecta** é uma aplicação web focada em aproximar e conectar soluções para o setor do agronegócio. Desenvolvido com uma interface moderna e responsiva, o projeto utiliza as melhores práticas de front-end para proporcionar uma experiência fluida aos usuários.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da aplicação.
- **Tailwind CSS**: Estilização rápida, moderna e totalmente responsiva através de classes utilitárias via CDN.
- **Git & GitHub**: Controle de versão e gerenciamento do repositório.
- **Vercel**: Hospedagem e deploy contínuo da aplicação integrada ao GitHub.

## 📦 Como Executar o Projeto Localmente

1. Certifique-se de que está na pasta do projeto.
2. Para rodar o servidor local, utilize o comando:
   ```bash
   npx serve .
   ```
3. Abra o navegador no endereço indicado (geralmente `http://localhost:3000`).
